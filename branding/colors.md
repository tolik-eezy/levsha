# Levsha OS — Official Color Palette

All colors are defined in `chat-shell/src/style.css` and used consistently
across the boot splash, chat GUI, and branding.

## Primary

| Name           | Hex       | Usage                                    |
|----------------|-----------|------------------------------------------|
| Copper         | `#C67A52` | Primary accent, buttons, links, caret    |
| Copper Dark    | `#B56B45` | Hover state for primary buttons          |
| Copper Tint    | `#7A4A35` | Confirmation dialog titles               |

## Backgrounds

| Name             | Hex       | Usage                                  |
|------------------|-----------|----------------------------------------|
| Warm Parchment   | `#FBF8F3` | Main window background                 |
| Off-White        | `#FDFBF7` | Assistant message bubbles, overlays    |
| Sand             | `#F5F1EA` | User message bubbles, input bar, status|
| Code Background  | `#F7F4EE` | Code blocks, inline code               |
| Error Background | `#FBF2ED` | Error widget background                |
| Confirm Bg       | `#FDF5F0` | Destructive command confirmation       |
| Button Text      | `#FAF8F4` | Text on filled copper buttons          |

## Text

| Name           | Hex       | Usage                                    |
|----------------|-----------|------------------------------------------|
| Dark Brown     | `#3A3228` | Primary body text                        |
| Code Text      | `#4A3F35` | Code block text, inline code             |
| Muted          | `#6B5D4F` | Role labels, tool status, status bar     |
| Subtle         | `#A89B8C` | Placeholders, scrollbar, code headers    |

## Borders

| Name           | Hex       | Usage                                    |
|----------------|-----------|------------------------------------------|
| Border Light   | `#EBE6DC` | Card borders, dividers, input borders    |

## Semantic

| Name           | Hex       | Usage                                    |
|----------------|-----------|------------------------------------------|
| Success Green  | `#62B37B` | Connected status, tool success           |
| Error Copper   | `#C67A52` | Error/warning states (reuses primary)    |
